0 wardrobe skins (armor, weapon, back, gathering) grouped into 0 release windows between expansions. Tags come from GW2 Wiki category data (green “expansion content” badge) or an inferred release era from a skin's wiki page creation date (yellow “wiki: date” badge) – see the note at the bottom.

How to read this: a skin tagged expansion content was directly categorized by the GW2 Wiki under that release. A skin tagged inferred from wiki page date wasn't tagged with any release by the wiki (most Gem Store / crafted / dungeon / PvP / festival skins aren't) – its window is a best guess based on when its wiki article was first written, which usually tracks release closely but isn't guaranteed. No wiki page found means neither signal exists. Generated by the gw2-wardrobe-expansions pipeline – see README.md for the full methodology and re-run npm run all to refresh this page's data.

Settings

Add a Guild Wars 2 API key to sync your unlocked wardrobe and filter skins by whether you already have them. Create one at account.arena.net/applications with only the unlocks permission checked – nothing else is needed.

Stored only in this browser (localStorage) and sent directly to api.guildwars2.com – this site has no server, so it never passes through anywhere else. Clearing it below removes it immediately.
